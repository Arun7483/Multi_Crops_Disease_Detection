📌 Overview

AgriScan is a real-time AI-based system designed to detect diseases across multiple crop types using computer vision and deep learning. The project combines YOLOv8 object detection with Raspberry Pi 5 edge deployment for an affordable, scalable, and field-ready plant disease monitoring solution.

This system helps in early disease diagnosis, enabling farmers to take prompt, informed decisions and reduce crop loss.


🛠️ Key Features

📷 Real-time detection of plant diseases from leaf images

🧠 YOLOv8-based model trained on a diverse multi-crop dataset

🖼️ Bounding boxes + class labels with confidence scores

💻 Java application with SQL backend for managing data and user interaction

🖥️ User-friendly GUI for non-technical users

📊 Achieved 92% accuracy on validation dataset

🌐 Designed for future mobile & IoT integration


🔧 Hardware Components

🧠 Raspberry Pi 5 – for edge AI inference

📷 Raspberry Pi Camera Module – for real-time leaf image capture

🔌 Power Optimization – designed for low-resource environments

⚙️ System Workflow

1. Dataset Preparation: Combined open datasets (Kaggle, Roboflow) + custom images for multiple crops

2. Image Annotation: Used LabelImg for bounding box generation

3. Model Training: Trained YOLOv8 model in Jupyter Lab (PyTorch backend)

4. Evaluation: Achieved 92% accuracy on test set

5. Software Integration: Developed Java GUI + Python backend for real-time interaction

6. Hardware Deployment: Deployed model on Raspberry Pi 5 with camera for live detection

7. Output: GUI shows disease classification, confidence score, and crop type
